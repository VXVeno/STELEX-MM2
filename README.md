# STELEX MM2

Premium Murder Mystery 2 script by **Veno**.

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/VXVeno/STELEX-MM2/refs/heads/main/loader.lua"))()
```

Paste into your executor and run.

## Controls

| Key | Action |
|-----|--------|
| **Insert** / **RightShift** | Open / close menu |
| **End** | Panic (disable features) |

## Features

- **Visuals** — ESP (box, skeleton, health, names, tracers, fill), Gun/Coin ESP, Chams, Fullbright
- **Combat** — Aimbot, Silent Aim, Knife Aim, Kill Aura, FOV
- **Farm** — Coin Farm, Auto Gun
- **Player** — Speed, Jump, Fly, Noclip
- **Misc** — Watermark, FPS Boost, Potato Mode, Config save
